# Weft Marketplace: A Comprehensive Guide to Sellable Agentic Assets

The Model Context Protocol (MCP) and Agent2Agent (A2A) protocol unlock a massive ecosystem for agentic commerce. By acting as the bridge for external systems, tools, and context, these protocols enable large language models (LLMs) to move beyond static knowledge and take real-world actions. 

Weft, acting as a global marketplace, allows developers to monetize the specific components that make AI agents capable and useful. Here is an exhaustive look at the real-world assets developers can push to Weft, categorized by the core primitives that agents consume.

---

### 1. Agent Skills (The "How-To" Logic)
Skills represent specialized domain expertise translated into step-by-step procedures that guide an agent's workflow. These are typically plain-language instructions (like a `SKILL.md` file) combined with logic scripts.
*   **Code Review Playbooks:** A skill that teaches an IDE agent exactly how to review a pull request for a specific framework (e.g., "Next.js Security Audit Skill"), scanning for known vulnerabilities.
*   **Incident Response Playbooks:** Operational workflows that instruct an agent to scan server logs, check deployment histories, and systematically identify the root cause of crashes.
*   **Legal Review Checklists:** Domain expertise distilled into a skill that guides an agent to scan a contract for specific red flags, unacceptable terms, or missing clauses.
*   **Data Analysis Pipelines:** Step-by-step procedures detailing how an agent should clean, analyze, and format a specific type of financial or scientific dataset.
*   **Compliance Workflows:** Automated checks that ensure code, infrastructure, or documentation meets specific industry standards (e.g., GDPR, HIPAA, or SOC2 compliance checks).

### 2. MCP Tools (The "Actions")
Tools are executable functions that allow an AI to take action in external systems or perform computations. They represent the "hands" of the agent, and developers can sell access to highly specialized, pre-built actions.
*   **Database Query Generators:** Tools that safely translate natural language into secure, optimized SQL queries tailored to specific enterprise database schemas.
*   **Jira/Ticket Creators:** Automation tools that take raw agent context (like a crash report) and format it into a properly structured bug report or operational ticket.
*   **SaaS Automation Triggers:** Connectors that execute actions in external platforms, such as updating a CRM record, creating a Slack channel, or provisioning software licenses via APIs.
*   **Code Execution Environments:** Sandboxed, secure environments where an agent can run generated Python or Bash scripts to test logic before committing it.
*   **Web Scraping/Browser Automation:** Tools that allow an agent to navigate to a URL, extract specific structured data, and return it cleanly for processing.
*   **Cryptographic Functions:** Specialized tools providing hashing, encryption, or blockchain interactions (e.g., wallet authentication) for agents.

### 3. MCP Resources (The "Context Data")
Resources provide the ambient context an AI model needs to reason accurately. They act as the "memory" or "knowledge base" for the agent, providing read-only access to highly valuable, curated data.
*   **Proprietary API Responses:** Paid access to live, high-value data feeds, such as real-time weather, financial market data, or threat intelligence feeds.
*   **Curated Knowledge Bases:** Pre-packaged documentation, such as an entire organization's governance policies, internal wikis, or specialized industry terminology dictionaries.
*   **Database Schemas:** The structural blueprints of complex databases, allowing an agent to understand the relationships between tables so it can query the data effectively.
*   **SaaS Utilization Records:** Datasets showing software inventory and usage metrics, crucial for IT optimization or cost-saving agents.
*   **Configuration Templates:** Standardized, best-practice boilerplate configurations (e.g., Kubernetes YAMLs, Dockerfiles, or Terraform scripts) that agents can use as starting points.
*   **Static Digital Assets:** Binary data files that agents can retrieve and utilize, such as 3D models (GLTF/OBJ), audio files, or curated datasets (handled via A2A `FileParts`).

### 4. MCP Prompts (The "Templates")
Prompts are reusable, engineered templates that guide how an AI interacts, structures its questions, or generates output. They act as the "instruction manual" for the LLM.
*   **Workflow Structuring Prompts:** Multi-step prompts that guide an agent through a complex, multi-stage process (e.g., a "New Employee Onboarding" prompt that triggers a sequence of actions across HR systems).
*   **Few-Shot Examples:** Highly optimized prompt templates that include perfectly crafted examples (inputs and ideal outputs) to ensure the agent interacts with a specific tool flawlessly.
*   **Specialized Analysis Prompts:** Templates designed to force the LLM into a specific analytical mindset, ensuring consistent formatting and deep analysis (e.g., `/summarize_financial_report` or `/analyze_security_vulnerability`).

### 5. Computer Vision & Machine Learning Assets
Because the Weft SDK acts as an A2A wrapper, it can also serve specialized models or logic layers beyond just text-based LLMs.
*   **Trained Model Weights:** Specialized weights for smaller, locally executable models (e.g., a custom YOLO model trained to detect a specific type of manufacturing defect or specialized medical imagery).
*   **Object Detection Logic:** Scripts that combine computer vision models with specific business logic (e.g., an "APARAS" script that counts bus passengers and audits ticket revenue).
